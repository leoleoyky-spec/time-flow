# お手本リールの分析手順（初回のみ）

入力：お手本の画面収録ファイル（ユーザーがアップロード）。

1. 0.25秒ごとにフレームを抜き、一覧画像にして Read で見る
   ```bash
   $FF -i ref.mp4 -vf "fps=4,scale=180:-1,tile=8x4" ref_sheet_%02d.png
   ```
   文字の出る/消えるタイミングは、該当区間を `fps=30` で抜き直して確定する。
2. 次を記録し `style.json` に書く：
   - テロップ1枚の平均表示秒数 → `rhythm.seconds_per_caption`
   - 出方（フェード/ポップ）と所要時間 → `rhythm.fade_in`
   - 種類ごと（普通/囲み/冒頭フック/最後のCTA）の 文字サイズ（1080幅換算）・文字色・フチ太さと色・囲みの色/余白/角丸/枠線 → `types.*`
     色は拡大フレームをPillowで `getpixel` して16進で取る。
   - 位置（画面高さに対する文字中心の割合）→ `position`
   - 部分的に色が変わる強調語 → `highlight_color`（台本で `[語]` と書くとこの色になる）
   - フォント：形（ゴシック/丸ゴ/明朝、太さ）から近い無料フォントを選び `font.path`。入手できない場合は IPAゴシック のまま、ユーザーに「近いフォント名」を伝える。
3. `"analyzed": true` にして、分析メモ（秒数表など）をこのファイル末尾に追記し、コミット・プッシュする。
4. お手本の音声は分析にも使わない（曲名だけ控えて、ユーザーに「音源を使う」を案内）。
