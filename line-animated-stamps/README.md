# LINE アニメーションスタンプ 一括作成ツール

**透過PNGのイラストを1枚ずつ用意して、CSVに「動き方」を書くだけ**で、
LINE Creators Market のアニメーションスタンプ仕様を満たすAPNG一式と、
そのままアップロードできるZIPを作るツールです。

- コマごとの絵を描かなくても大丈夫です。1枚絵に「跳ねる・揺れる・震える」などの動きを自動でつけます
- 文字入れもCSVに書くだけでできます
- メイン画像（240×240）とタブ画像（96×74）も自動で作ります
- 仕様チェック（サイズ・フレーム数・再生時間・300KB以下）も自動で行います
- 動きを自分で描きたい場合は、連番PNGを入れたフォルダを指定することもできます

## 全体の流れ（一番かんたんな方法）

```
① イラストを8枚描く（透過PNG）  →  ② CSVに動きと文字を書く  →  ③ コマンド1回で作成
                                                                          ↓
                    ⑤ 審査リクエスト  ←  ④ Creators Market にZIPをアップロード
```

## 1. 準備（最初の1回だけ）

```bash
pip install -r requirements.txt
python make_stamps.py --demo     # サンプルで動作確認
```

`demo/output/preview.html` をブラウザで開くと、動きを確認できます。

## 2. イラストを用意する

- **8枚 / 16枚 / 24枚** のどれか（まずは8枚がおすすめ）
- 背景は**透過**したPNG（サイズは自由です。自動で縮小・配置します）
- `input/01.png`, `input/02.png` … のように `input/` フォルダに入れます

## 3. `stamps.csv` を編集する

Excel やスプレッドシートで開けます。

| file | motion | text | frames | seconds | loops |
|---|---|---|---|---|---|
| input/01.png | bounce | ありがとう | 10 | 1 | 3 |
| input/02.png | pop | OK! | 10 | 1 | 3 |

| 列 | 意味 |
|---|---|
| `file` | 画像ファイル。**フォルダを指定すると、その中の連番PNGをそのままコマとして使います** |
| `motion` | 動き方（下の表を参照） |
| `text` | 入れる文字（空欄なら文字なし） |
| `frames` | コマ数 5〜20（既定 8） |
| `seconds` | 1回の再生にかかる秒数 1〜4（既定 1） |
| `loops` | 繰り返し回数 1〜4（既定 2）。`seconds × loops` が4秒を超える場合は自動で調整します |

### 使える動き（`python make_stamps.py --list-motions`）

| motion | 動き |
|---|---|
| `bounce` | ぴょんぴょん跳ねる |
| `jump` | 大きく1回ジャンプ |
| `shake` | ぷるぷる震える |
| `swing` | 左右にゆらゆら |
| `float` | ふわふわ浮かぶ |
| `heartbeat` | ドキドキ拡大縮小 |
| `pop` | ポンッと飛び出す |
| `spin` | くるっと1回転 |
| `fadein` | じわっと現れる |
| `zoom` | グッと迫る |

どの動きも**最後のコマで元の姿勢に戻ります**。LINEでは再生が終わった後に最後のコマが表示され続けるためです。

## 4. 作成する

```bash
python make_stamps.py stamps.csv
```

`output/` に次のファイルができます。

```
output/
├── 01.png 〜 08.png          スタンプ本体（APNG, 320×270）
├── main.png                  メイン画像（APNG, 240×240）※ --main 3 で3番を使う
├── tab.png                   トークルームタブ画像（PNG, 96×74）
├── preview.html              動きの確認用
└── line_animation_stamp.zip  ← これをアップロードする
```

文字入れには日本語フォントが必要です。自動で見つからない場合は `--font` で指定してください
（例: `--font "C:/Windows/Fonts/meiryob.ttc"`）。

## 5. LINE Creators Market で申請する

1. [LINE Creators Market](https://creator.line.me/ja/) にLINEアカウントでログインし、クリエイター登録をする（初回のみ）
2. マイページの「新規登録」から **「アニメーションスタンプ」** を選ぶ
3. 「アイテム情報」に、タイトル・説明文・クリエイター名・コピーライトなどを入力する
   （英語の情報も必要です）
4. 「スタンプ画像」タブで個数を選んだあと、**「ZIPファイルをアップロード」** から
   `line_animation_stamp.zip` をアップロードする
5. 「タグ設定」「販売情報（価格など）」を入力する
6. 「リクエスト」ボタンを押して審査に出す → 承認されたら「リリース」を押すと販売開始

> 画面の名前や必須項目は変わることがあります。申請前に Creators Market の
> 「アニメーションスタンプ制作ガイドライン」と「審査ガイドライン」も確認してください。

## LINEアニメーションスタンプの仕様（このツールが自動で満たすもの）

| 項目 | 仕様 |
|---|---|
| 個数 | 8 / 16 / 24 個 |
| スタンプ画像 | APNG、最大 W320×H270px（縦横どちらかは270px以上）、背景透過 |
| メイン画像 | APNG、W240×H240px |
| タブ画像 | PNG、W96×H74px |
| フレーム数 | 5〜20 |
| ループ数 | 1〜4 |
| 再生時間 | 最大4秒（1・2・3・4秒のいずれか） |
| ファイルサイズ | 1ファイル300KB以下（超える場合は減色・コマ間引きで自動圧縮） |

すでにある画像を確認したいときは、仕様チェックだけを行うこともできます。

```bash
python make_stamps.py --validate output/
```
